# wdbclub-miniapp — контекст проекта

Telegram-мини-апп клуба WDB Club. Сейчас — кликабельный прототип:
один `index.html` без сборки, данные вымышленные, состояние в
`localStorage`. Публикуется через GitHub Pages из `main`:
https://vmalov.github.io/wdbclub-miniapp/

Процесс — `PROCESS.md` из `vmalov/dev-guides` (тикет → DoD → дизайн → ТЗ →
код и тесты → PR → мердж владельцем). Документы экранов —
`docs/screens/` по шаблону `_template.md`, индекс — `docs/screens/README.md`.

## Дизайн-система — обязательна

Описание — `docs/design-system.md`, живая страница — `design-system.html`,
файлы — `ds/tokens.css` и `ds/components.css` (#1).

- Экраны (и макеты, и код) собираются только из компонентов и токенов ДС.
  Цветов, шрифтов и скруглений мимо токенов в коде экранов нет.
- Нужного компонента в ДС нет — не рисовать и не кодировать молча: сначала
  предложить владельцу похожий существующий или новый; новый компонент
  появляется в ДС (CSS + живая страница с местом использования) только
  после его явного «ок».
- Расхождение экрана или макета с ДС — владельцу списком «где — что на
  экране — что в ДС», правка только после его решения.

## Макеты

Макеты экранов лежат в репозитории (решение владельца 09.11.2026, #1):
HTML-страницы на файлах ДС, ссылка на превью ветки — в тикет и в документ
экрана, после мерджа — на GitHub Pages.

## Тесты

`npm test` — проверки ДС (`tests/ds.test.mjs`, `node:test`, без
зависимостей).
