макетов. «Ок» владельца на ТЗ — согласие с ними; иначе правим ТЗ до кода.

   записи, очередь и машины хранятся на сервере, приложение работает только

   место в очереди) и шкала занятых мест «N из M».
4. **Удаление машины** (#8): машину из записи на будущее мероприятие
   удалить нельзя — сначала отменить запись.
5. **Логотип** — растровый с сайта клуба (`ds/img/logo-wdb-club.png`).
6. **Одно мероприятие** (#10, решение владельца 10.11.2026): в приложении

   `tests/fixtures/data.js`: на них идут юнит-тесты и e2e, в приложении их нет.

## Правила записи

**Мероприятие «без машины»** (`noCar`, #10): «Записаться» записывает сразу,
без шторок «Сначала — машина» и выбора машины; машина в записи не хранится.
В списке участников — аватар с инициалами (`.avatar`), имя и @username,
без модели и госномера; миниатюры у незаписанных — инициалы. Пункты 2–3
ниже к нему не относятся.

1. **Занято мест** = `others.length` + 1, если моя запись `on`.
2. **Записаться** можно, только если у меня есть хотя бы одна машина.
   Машин нет — шторка «Сначала — машина» → форма машины «из записи» →
   «Сохранить и записаться» сохраняет машину и сразу записывает на ней.
3. **Одна машина** — запись без вопросов. **Несколько** — шторка выбора,
   по умолчанию отмечена последняя использованная, иначе первая.
4. **Места есть** (`занято < cap`) → статус `on`, тост «Вы записаны на
   „<название>“».
5. **Мест нет** → кнопка «Встать в лист ожидания» (с выбором машины, как в
   п. 3) → статус `wait`. Моё место в очереди = `waitOthers.length` + 1.
6. **Отменить запись** — сразу, без подтверждения (действие обратимо):
   запись удаляется, тост «Запись отменена». **Выйти из листа ожидания** —
   так же, тост «Вы вышли из листа ожидания».
7. Освободившееся место автоматически получает первый из листа ожидания
   (#8); он видит «Записаны», когда откроет приложение.
8. Прошедшие мероприятия (дата раньше сегодняшней) в «Ближайших» не
   показываются; запись на них недоступна. В календаре они видны.

## Видимость

| Что | Записан / в очереди | Не записан |
|---|---|---|
| Число участников и шкала | да | да |
| Миниатюры (фото машин) | да | да |
| Имя, машина, Telegram | да | нет |
| Госномер другого участника | если он разрешил (`plate` не `null`) | нет |
| Мой госномер | всегда в моём профиле; другим — по моему переключателю | — |

## Telegram

Внутри Telegram: `ready()`, `expand()`, цвет шапки и фона — `--bg`;
«Назад» — системная `BackButton` (своя кнопка «назад» в шапке скрыта);
тактильный отклик на запись (`HapticFeedback`). Вне Telegram — своя шапка
с кнопкой «назад».

## Не входит в первый этап

Уведомления, аналитика событий и отправка ошибок в трекер (появятся вместе с сервером —
отдельными тикетами), страница Release Notes (по dev-guides — отдельный
тикет).
