## Допущения (до ответа владельца)

Открытые вопросы из DoD #2 закрыты в ТЗ вариантами из согласованных
макетов. «Ок» владельца на ТЗ — согласие с ними; иначе правим ТЗ до кода.

1. **Прототип, не сервер.** Данные мероприятий, партнёров и других
   участников — вымышленные, в коде (`app/data.js`). Свои машины и записи
   участник хранит в браузере (`localStorage`, ключ `wdb-stage1`). Записи
   других участников не видны другим устройствам.
2. **Полный список участников** видят записанные на мероприятие и стоящие в
   его листе ожидания. Остальные — только миниатюры (фото машин) и число.
3. **Прогресс мероприятия** — статус участника («Записаны», «Ожидание»,
   место в очереди) и шкала занятых мест «N из M».
4. **Удаления машины нет** (в DoD — создать, сохранить, изменить).
5. **Логотип** — растровый с сайта клуба (`ds/img/logo-wdb-club.png`).

## Сущности

| Сущность | Поля | Откуда |
|---|---|---|
| Мероприятие | `id`, `type` (Заезд, Встреча…), `name`, `date` (ISO), `time`, `gather` (время сбора, может отсутствовать), `place`, `address`, `desc`, `cap` (лимит мест), `partnerId`, `cover` (фото), `others` — вымышленные участники, `waitOthers` — вымышленная очередь | `app/data.js` |
| Партнёр | `id`, `mark` (2 буквы), `name`, `since`, `about`, `offer`, `until`, `addr`, `tel`, `site` | `app/data.js` |
| Участник (другой) | `name`, `tg`, машина: `brand`, `model`, `year`, `color`, `photo`, `plate` или `null` (номер скрыт) | `app/data.js` |
| Моя машина | `id`, `brand`, `model`, `year`, `color`, `plate`, `showPlate` (bool), `photo` (data URL, ужато до 900 px по ширине) | `localStorage` |
| Моя запись | `eventId` → `{ status: 'on' \| 'wait', carId, at }` | `localStorage` |
| Я | имя и фото — из Telegram (`initDataUnsafe.user`), вне Telegram — «Иван Петров» | Telegram |

## Правила записи

1. **Занято мест** = `others.length` + 1, если моя запись `on`.
2. **Записаться** можно, только если у меня есть хотя бы одна машина.
   Машин нет — шторка «Сначала — машина» → форма машины «из записи» →
   «Сохранить и записаться» сохраняет машину и сразу записывает на ней.
3. **Одна машина** — запись без вопросов. **Несколько** — шторка выбора,
   по умолчанию отмечена последняя использованная, иначе первая.
4. **Места есть** (`занято < cap`) → статус `on`, тост «Вы записаны на
   „<название>“».
5. **Мест нет** → кнопка «Встать в лист ожидания» (с выбором машины, как в
   п. 3) → статус `wait`. Моё место в очереди = `waitOthers.length` + 1.
6. **Отменить запись** — сразу, без подтверждения (действие обратимо):
   запись удаляется, тост «Запись отменена». **Выйти из листа ожидания** —
   так же, тост «Вы вышли из листа ожидания».
7. Освободившееся место в прототипе никого не продвигает: очередь
   вымышленная. Продвижение очереди — на этапе с сервером.
8. Прошедшие мероприятия (дата раньше сегодняшней) в «Ближайших» не
   показываются; запись на них недоступна. В календаре они видны.

## Видимость

| Что | Записан / в очереди | Не записан |
|---|---|---|
| Число участников и шкала | да | да |
| Миниатюры (фото машин) | да | да |
| Имя, машина, Telegram | да | нет |
| Госномер другого участника | если он разрешил (`plate` не `null`) | нет |
| Мой госномер | всегда в моём профиле; другим — по моему переключателю | — |

## Telegram

Внутри Telegram: `ready()`, `expand()`, цвет шапки и фона — `--bg`;
«Назад» — системная `BackButton` (своя кнопка «назад» в шапке скрыта);
тактильный отклик на запись (`HapticFeedback`). Вне Telegram — своя шапка
с кнопкой «назад».

## Не входит в первый этап

Сервер и общая база, уведомления, продвижение очереди, удаление машины,
аналитика событий и отправка ошибок в трекер (появятся вместе с сервером —
отдельными тикетами), страница Release Notes (по dev-guides — отдельный
тикет).
